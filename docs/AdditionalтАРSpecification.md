# Дополнительная спецификация

## Нефункциональные требования

### Производительность
- Время холодного старта < 2 с на среднебюджетном устройстве (Snapdragon 665 / 4 ГБ RAM).
- Все запросы к Room выполняются на `Dispatchers.IO`; UI-поток никогда не блокируется.
- Списки отображаются через `LazyColumn` / `LazyVerticalGrid` для эффективной переработки элементов.

### Надёжность
- WorkManager повторяет неудавшиеся обновления курсов с экспоненциальной задержкой (максимум 3 попытки).
- Версия базы данных Room управляется через миграции; `fallbackToDestructiveMigration` используется только в debug-сборке.

### Безопасность
- Никакие чувствительные данные пользователя не передаются во внешние сервисы (только анонимные запросы курсов валют).
- API НБРБ не требует аутентификации.
- Release APK подписывается приватным хранилищем ключей, которое хранится в виде секрета GitHub Actions (никогда не коммитируется в репозиторий).

### Совместимость
- Min SDK 26 (Android 8.0) — охватывает > 95 % активных устройств.
- Target SDK 35 (Android 15).
- Поддержка отображения «от края до края» (`enableEdgeToEdge()`).

### Доступность
- Все интерактивные элементы имеют `contentDescription` для TalkBack.
- Безопасность для людей с цветовой слепотой: суммы различаются по префиксу +/− и цвету (зелёный/красный) одновременно.
- Размер области нажатия ≥ 48 dp согласно рекомендациям Material Design.

### Интернационализация
- Все видимые пользователю строки вынесены в `res/values/strings.xml`.
- Даты форматируются через `DateTimeFormatter` с учётом локали устройства.
- Суммы валют форматируются через `String.format("%.2f")` (без жёстко заданной локали).
