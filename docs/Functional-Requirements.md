# Функциональные требования

## Диаграмма вариантов использования (текст)

```
Актор: Пользователь
─────────────────────────────────────────
UC-01  Добавить транзакцию
UC-02  Редактировать транзакцию
UC-03  Удалить транзакцию (свайп)
UC-04  Просмотр списка транзакций (фильтр по периоду)
UC-05  Просмотр сводки баланса (доходы / расходы)
UC-06  Просмотр статистики (по категориям, дневной график)
UC-07  Установить бюджет категории
UC-08  Изменить валюту отображения
UC-09  Просмотр актуальных курсов валют
UC-10  Получить уведомление о превышении бюджета
UC-11  Получить уведомление об обновлении курса валют
```

---

## Текстовые сценарии

### UC-01 Добавить транзакцию

| Поле | Значение |
|---|---|
| **Триггер** | Пользователь нажимает FAB (+) на экране «Главная» |
| **Предусловие** | Приложение открыто, экран «Главная» отображён |
| **Основной поток** | 1. Открывается экран «Добавить транзакцию». 2. Пользователь переключает тип: Расход / Доход. 3. Вводит сумму (дробное число, до 10 цифр). 4. Выбирает категорию из сетки. 5. При необходимости меняет дату через date picker. 6. При необходимости вводит примечание. 7. Нажимает «Сохранить». 8. Транзакция сохраняется в Room DB. 9. Приложение возвращается на экран «Главная». |
| **Альтернативный поток** | 3а. Сумма пустая или равна 0 → показывается ошибка валидации, сохранение не выполняется. 4а. Категория не выбрана → показывается ошибка валидации. |
| **Постусловие** | Новая транзакция отображается в списке на экране «Главная». |

---

### UC-03 Удалить транзакцию

| Поле | Значение |
|---|---|
| **Триггер** | Пользователь свайпает карточку транзакции влево |
| **Основной поток** | 1. За карточкой появляется иконка удаления. 2. Диалог подтверждения: «Удалить транзакцию? Это действие нельзя отменить.» 3. Пользователь нажимает «Удалить». 4. Транзакция удаляется из БД. |
| **Альтернативный поток** | 3а. Пользователь нажимает «Отмена» → карточка возвращается на место, ничего не удаляется. |

---

### UC-09 Просмотр актуальных курсов валют

| Поле | Значение |
|---|---|
| **Триггер** | Пользователь открывает экран «Настройки» (курсы загружаются автоматически) |
| **Основной поток** | 1. Приложение обращается к API НБРБ (`api.nbrb.by/exrates/rates`). 2. Курсы USD, EUR, RUB, CNY, GBP отображаются в таблице. 3. Пользователь может нажать «Обновить» для принудительной перезагрузки. |
| **Альтернативный поток** | Сеть недоступна → под таблицей отображается сообщение об ошибке. |
| **Фоновый режим** | WorkManager запускает `CurrencyRefreshWorker` каждые 6 часов автоматически. |
